# Architecture decision records

Decisions are numbered in one series and named `ADR-VEC-NN-<slug>.md`, for example `ADR-VEC-03-workflow-and-template-model.md`; a citation uses the same `ADR-VEC-NN` form. Numbers 02 to 11 were reserved by [ADR-VEC-01](./ADR-VEC-01-product-requirements-and-features.md) for its planned follow-on decisions, so a number may be taken before its record is written. A decision usually starts as a spike document in [`docs/spikes/`](../spikes/) written to be lifted into its record.
